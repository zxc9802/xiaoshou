# 可配置的分析知识库开关设计

## 目标

将知识库是否参与销售分析改为显式配置。默认情况下，分析直接使用 ChatGPT，根据对话、客户背景和本地安全分类生成结果，不读取、检索、注入或引用知识库。知识库仍保留上传、审核、发布、存储、查看等完整能力，作为独立演示功能。

需要保留恢复原有知识增强分析的能力，因此不删除知识检索实现、结果兼容字段或历史数据。

## 配置

- 在 `AppConfig` 中增加 `analysisKnowledgeEnabled: boolean`。
- 使用环境变量 `ANALYSIS_KNOWLEDGE_ENABLED` 控制。
- 只有值为字符串 `true` 时开启，其余值和未配置状态都视为关闭。
- 默认部署无需修改环境变量，即采用无知识库的 ChatGPT 分析。

## 分析数据流

### 关闭时

1. 对话解析和本地安全分类保持不变。
2. 分析服务跳过 `repository.listKnowledge` 和 `retrieveKnowledge`，也不访问向量索引。
3. 规则基线和模型生成均使用空知识列表。
4. ChatGPT 提示词不包含“已审核知识”、知识事实 JSON、`sourceIds` 或必须引用知识库的要求。
5. 新分析结果的 `sourceReferences` 固定为空数组。
6. 不生成“缺少已审核依据”“资料库中未找到依据”等知识库警告。
7. 分析结果和复盘数据不标记知识缺口。

### 开启时

保留当前流程：读取已发布知识，执行关键词或向量检索，将检索结果传给规则基线和 ChatGPT，并生成受校验的知识引用。现有检索策略、向量索引和知识事实约束不在本次改动范围内。

## 模型提示词

模型提示词根据 `analysisKnowledgeEnabled` 选择两种模式：

- 关闭模式仅包含销售分析角色、合规边界、对话、客户背景、本地安全分类和输出 JSON 约束。
- 开启模式继续包含已审核知识、知识引用约束和 `sourceIds`。

两种模式共用销售策略、拒绝收尾、人工升级、隐私保护和输出结构要求。关闭知识库不会放松这些通用安全约束，也不会改成规则引擎生成；当 `MODEL_DRIVER=openai_compatible` 时仍由配置的 ChatGPT/OpenAI 兼容模型生成分析。

## 接口和历史数据兼容

- 保留 `sourceReferences`、`knowledgeGap`、`knowledgeGapCount` 等类型和接口字段。
- 关闭模式下，新分析的 `sourceReferences` 为 `[]`，新复盘的 `knowledgeGap` 为 `false`，聚合的 `knowledgeGapCount` 为 `0`。
- 历史分析和复盘记录无需迁移，已有知识引用仍可存在于存储中。
- 知识库开关只影响新分析的生成链路，不删除或改写历史记录。

## 界面行为

- 关闭模式下，分析结果页不显示“依据来源”、资料库风险提示或知识引用相关文案。
- 关闭模式下，复盘中心不显示“知识缺口”指标和单条复盘的知识缺口提示。
- 开启模式下，上述知识相关界面恢复显示。
- 前端需要从服务端获得当前功能状态，不能依赖构建时环境变量，以保证同一前端包可随服务端配置切换。
- 知识库页面始终显示并保持可操作，不受开关影响。

## 错误处理

- 关闭模式不执行知识检索，因此知识仓库或向量服务不可用不会阻断分析。
- 开启模式继续沿用现有检索降级和分析重试行为。
- 模型调用失败、解析失败、对话确认和人工升级仍沿用现有处理逻辑。
- 配置值非法时按关闭处理，不增加启动失败分支。

## 测试

采用测试驱动方式覆盖以下行为：

1. 配置未设置、设置为 `false` 或非法值时关闭；只有 `true` 时开启。
2. 关闭时分析服务不调用 `listKnowledge`，不调用向量检索，并直接进入生成阶段。
3. 关闭时模型提示词不包含知识库内容、知识事实区块和引用要求，结果引用为空且无知识缺口警告。
4. 开启时保留现有知识检索、提示词注入和引用行为。
5. 关闭时新复盘的 `knowledgeGap` 为 `false`，聚合值为 `0`。
6. 前端根据服务端功能状态隐藏或显示分析结果和复盘中心的知识相关区域。
7. 现有知识库导入、审核、存储、发布和检索单元测试继续通过。
8. 完整运行单元测试、类型检查和生产构建。

## 不在本次范围

- 不删除知识库页面、API、数据库记录、对象存储或向量索引。
- 不修改知识导入、审核、拆分、合并、发布和归档流程。
- 不迁移或清理历史分析中的知识引用。
- 不更换当前模型供应商、模型名称或 API 协议。
- 不新增管理界面开关；本次只通过服务端环境变量控制。
